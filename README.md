# EMS Data Service

The EMS Data Service is a FastAPI application for recording and retrieving emergency medical service incidents. It exposes a REST API that supports creating, searching, updating, and deleting incidents while persisting data to a SQLite database.

## Features

- Health check endpoint for simple monitoring.
- CRUD API for EMS incidents with filtering by incident type, severity, and status.
- Automatic database schema creation using SQLAlchemy.
- CORS enabled for ease of integration with other services or frontend applications.
- Automated tests that exercise the primary API flows using FastAPI's `TestClient`.

## Getting Started

### Prerequisites

- Python 3.11+
- `pip` package manager

### Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Running the Application

```bash
uvicorn app.main:app --reload
```

The service will start on `http://127.0.0.1:8000`. API documentation is automatically generated and available at `http://127.0.0.1:8000/docs`.

### Running Tests

```bash
pytest
```

### Project Layout

```
app/
├── crud.py         # Data-access helpers for incidents
├── database.py     # Database engine and session management
├── main.py         # FastAPI entrypoint and routes
├── models.py       # SQLAlchemy ORM models
└── schemas.py      # Pydantic models used by the API
requirements.txt    # Python dependencies
README.md           # Project documentation
```

## API Overview

| Method | Path | Description |
| ------ | ---- | ----------- |
| GET | `/health` | Health check endpoint |
| GET | `/incidents` | List incidents with optional query filters |
| POST | `/incidents` | Create a new incident |
| GET | `/incidents/{id}` | Retrieve an incident by ID |
| PUT | `/incidents/{id}` | Replace an incident |
| PATCH | `/incidents/{id}` | Partially update an incident |
| DELETE | `/incidents/{id}` | Remove an incident |

All endpoints return JSON responses. Detailed schemas and example requests/responses can be explored via the interactive API docs generated by FastAPI.

## Development Notes

- The default SQLite database file (`ems.db`) is created in the project root the first time the API runs.
- Adjust the database connection string in `app/database.py` if you need to target another database engine.
- When writing tests, override `get_db` dependency as demonstrated in `tests/test_incidents.py` to isolate test data.
